        YouTube അപ്‌ലോഡ് പേജ് തുറക്കുക

        YouTube-ന്റെ അപ്‌ലോഡ് ബോക്സും ക്ലിപ്പ് ഫോൾഡറും തുറക്കും. ഫോൾഡറിൽ നിന്ന് ക്ലിപ്പ് ബോക്സിലേക്ക് വലിച്ചിടുക.

        ശീർഷകം, വിവരണം, അപ്‌ലോഡ്

        പേര് കൊടുത്താൽ വിവരണവും ഹാഷ്‌ടാഗുകളും അതനുസരിച്ച് നിറയും. വിവരണം നിങ്ങൾക്ക് മാറ്റാം.

        ക്രമീകരണങ്ങൾ

        നിങ്ങളുടെ വീഡിയോകളോ വിവരങ്ങളോ തനിയെ എങ്ങും അയയ്ക്കുന്നില്ല. YouTube ലിങ്ക് ഉപയോഗിക്കുമ്പോൾ yt-dlp ആ വീഡിയോ ഡൗൺലോഡ് ചെയ്യും; YouTube അപ്‌ലോഡ് സജ്ജമാക്കിയാൽ നിങ്ങൾ "അപ്‌ലോഡ്" അമർത്തുന്ന ക്ലിപ്പ് മാത്രം YouTube-ലേക്ക് പോകും; ആപ്പ് തുറക്കുമ്പോൾ പുതിയ പതിപ്പ് ഉണ്ടോ എന്നറിയാൻ GitHub-ൽ നിന്ന് ഒരു ചെറിയ ഫയൽ വായിക്കും.

        AI സഹായി: ശീർഷകവും വിവരണവും എഴുതാൻ (ഓപ്ഷണൽ, ഈ PC-യിൽ മാത്രം)

        ഈ PC-യിൽ തന്നെ ഓടുന്ന ഒരു AI മോഡൽ ക്ലിപ്പിലെ ചിത്രങ്ങൾ നോക്കി ശീർഷകം, വിവരണം, ഹാഷ്‌ടാഗുകൾ എന്നിവ നിർദ്ദേശിക്കും. ഒന്നും ഇന്റർനെറ്റിലേക്ക് പോകില്ല. ക്ലിപ്പ് കണ്ടെത്തൽ ഇപ്പോഴും AI ഇല്ലാതെ തന്നെ.

        1. Ollama എന്ന സൗജന്യ പ്രോഗ്രാം ഇൻസ്റ്റാൾ ചെയ്യുക: ollama.com
        2. ഒരു കറുത്ത ജാലകത്തിൽ (Command Prompt) ഇത് ഒരിക്കൽ ഓടിക്കുക, ചിത്രം കാണാൻ കഴിയുന്ന ഒരു മോഡൽ ഡൗൺലോഡ് ആകും (ഏകദേശം 3 GB): ollama pull gemma3:4b
        3. ഇവിടെ താഴെ ആ മോഡൽ തിരഞ്ഞെടുക്കുക.

        ചെറിയ മോഡലുകൾ തെറ്റുകൾ എഴുതാം, മലയാളം പ്രത്യേകിച്ച് മോശമാകാം. എഴുതിയത് വായിച്ച് തിരുത്തിയ ശേഷം മാത്രം ഉപയോഗിക്കുക. നല്ല ഗ്രാഫിക്സ് കാർഡ് ഇല്ലെങ്കിൽ ഒരു വിവരണത്തിന് ഒരു മിനിറ്റോ അതിലധികമോ എടുക്കാം.

        YouTube-ലേക്ക് നേരിട്ട് അപ്‌ലോഡ് (ഓപ്ഷണൽ)

        ബന്ധിപ്പിച്ചാൽ ഉണ്ടാക്കിയ Short ഒരു ബട്ടണിൽ നിങ്ങളുടെ ചാനലിലേക്ക് അപ്‌ലോഡ് ചെയ്യാം. നിങ്ങൾ "അപ്‌ലോഡ്" അമർത്തുന്ന ക്ലിപ്പ് മാത്രം YouTube-ലേക്ക് പോകും.

        1. Google Cloud Console-ൽ ഒരു പ്രോജക്റ്റിൽ "YouTube Data API v3" ഓൺ ചെയ്യുക.
        2. OAuth consent screen സജ്ജമാക്കി, നിങ്ങളുടെ Google അക്കൗണ്ട് "Test users"-ൽ ചേർക്കുക.
        3. Credentials → Create credentials → OAuth client ID → "Desktop app". JSON ഫയൽ ഡൗൺലോഡ് ചെയ്യുക.
        4. ആ ഫയലിന്റെ പേര് youtube_client.json എന്നാക്കി "എല്ലാ ഫയലുകളും" ഫോൾഡറിൽ (മുകളിൽ കാണാം) വയ്ക്കുക. എന്നിട്ട് ഇവിടെ "ബന്ധിപ്പിക്കുക" അമർത്തുക.

        ബന്ധിപ്പിച്ചാൽ ഒരു Google ലോഗിൻ ടോക്കൺ ഈ PC-യിലെ ഡാറ്റ ഫോൾഡറിൽ സൂക്ഷിക്കും. അത് വീഡിയോ അപ്‌ലോഡ് ചെയ്യാൻ മാത്രം അനുമതിയുള്ളതാണ്. ആ ഫോൾഡർ മറ്റാരുമായും പങ്കിടരുത്.

        Claude-മായി ബന്ധിപ്പിക്കുക (ഓപ്ഷണൽ)

        ബന്ധിപ്പിച്ചാൽ Claude-ൽ ടൈപ്പ് ചെയ്താൽ മതി, ഉദാ: “ഇന്നത്തെ സ്ട്രീമിലെ മികച്ച 5 നിമിഷങ്ങൾ കണ്ടെത്തി Shorts ആക്കൂ”. ആപ്പ് ഇല്ലാതെയും ഇതെല്ലാം ഇവിടെ തന്നെ ചെയ്യാം.

        Claude-ന് കിട്ടുന്നത്: ഫയൽ പേരുകൾ, ക്ലിപ്പ് സമയങ്ങളും സ്കോറും, ക്ലിപ്പ് ഫോൾഡറിന്റെ സ്ഥാനം. വീഡിയോ ഫയലുകൾ അയയ്ക്കുന്നില്ല. Claude-ന് ഈ ഫോൾഡറിനു പുറത്തുള്ള ഒന്നും വായിക്കാനോ ഡിലീറ്റ് ചെയ്യാനോ കഴിയില്ല.

        Claude Desktop

        Claude Desktop-ൽ: Settings → Developer → Edit Config. തുറക്കുന്ന claude_desktop_config.json ഫയലിൽ ഇത് ചേർക്കുക (ഫയലിൽ ഇതിനകം mcpServers ഉണ്ടെങ്കിൽ അതിനുള്ളിൽ clipfinder ഭാഗം മാത്രം ചേർക്കുക). സേവ് ചെയ്ത് Claude Desktop പൂർണ്ണമായി അടച്ച് വീണ്ടും തുറക്കുക.

        Claude Code

        മറ്റ് ഉപകരണങ്ങളിൽ നിന്ന് ഉപയോഗിക്കുക — Tailscale (ഓപ്ഷണൽ)

        PC-യിൽ ClipFinder ഓടിക്കൊണ്ടിരിക്കുമ്പോൾ ഫോണിൽ/ലാപ്ടോപ്പിൽ നിന്ന് ഇതേ പേജ് തുറക്കാം. ഇന്റർനെറ്റിൽ പൊതുവായി ഒന്നും തുറക്കില്ല: നിങ്ങളുടെ Tailscale അക്കൗണ്ടിലെ ഉപകരണങ്ങൾക്ക് മാത്രം, കൂടാതെ രഹസ്യ ലിങ്കും വേണം.

        1. PC-യിലും ഫോണിലും Tailscale ഇൻസ്റ്റാൾ ചെയ്ത് ഒരേ അക്കൗണ്ടിൽ ലോഗിൻ ചെയ്യുക. Tailscale അഡ്മിൻ പേജിൽ (DNS) MagicDNS, HTTPS certificates ഓൺ ചെയ്യുക.
        2. താഴെ PC-യുടെ Tailscale പേര് (പേര്.tailXXXX.ts.net) കൊടുത്ത് സേവ് ചെയ്യുക. ClipFinder അടച്ച് വീണ്ടും തുറക്കുക.
        3. PC-യിൽ ഈ കമാൻഡ് ഒരിക്കൽ ഓടിക്കുക (tailscale serve മാത്രം; funnel ഉപയോഗിക്കരുത്, അത് പൊതുവായി തുറക്കും).
        4. താഴെ കാണുന്ന ലിങ്ക് ഫോണിൽ തുറക്കുക.
