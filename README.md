# clipfinder — ഗെയിം സ്ട്രീമിൽ നിന്ന് Shorts ക്ലിപ്പുകൾ കണ്ടെത്താൻ

AI ഇല്ല, അക്കൗണ്ട് ഇല്ല, ചെലവ് ₹0. ശബ്ദവും സ്ക്രീനിലെ ചലനവും മാത്രം നോക്കി "ക്ലിപ്പ് ആകാൻ സാധ്യതയുള്ള" ഭാഗങ്ങളുടെ ലിസ്റ്റ്
ഉണ്ടാക്കുന്നു. **ഏത് ഉപയോഗിക്കണം എന്ന് നിങ്ങൾ തീരുമാനിക്കും.** തിരഞ്ഞെടുത്തവ 1080×1920 (9:16) MP4 ആയി ഉണ്ടാക്കും.
എല്ലാം നിങ്ങളുടെ കമ്പ്യൂട്ടറിൽ മാത്രം നടക്കുന്നു. ആപ്പിന്റെ സ്വന്തം കോഡ് ഒന്നും ഇന്റർനെറ്റിലേക്ക് അയയ്ക്കുന്നില്ല;
ഇന്റർനെറ്റ് ഉപയോഗിക്കുന്നത് yt-dlp മാത്രം (YouTube ലിങ്ക് ഡൗൺലോഡ് ചെയ്യുമ്പോഴും "yt-dlp അപ്ഡേറ്റ്" അമർത്തുമ്പോഴും).
**ഒരേയൊരു ഒഴിവ്, നിങ്ങൾ ഓൺ ചെയ്താൽ മാത്രം:** Claude കണക്ടർ (താഴെ). അത് ഉപയോഗിക്കുമ്പോൾ ഫയൽ പേരുകളും ക്ലിപ്പ് സമയങ്ങളും Claude-ലേക്ക് പോകും;
"ചിത്രം കാണാൻ അനുവദിക്കുക" കൂടി ഓൺ ആക്കിയാൽ ക്ലിപ്പിന്റെ ഒരു ചിത്രവും. വീഡിയോ ഫയലുകൾ ഒരിക്കലും അയയ്ക്കില്ല.

## വേഗത്തിൽ തുടങ്ങാൻ (Windows)
രണ്ട് വഴികൾ ഉണ്ട്. ആദ്യത്തേത് എളുപ്പം: Python, ffmpeg, yt-dlp എല്ലാം ഇൻസ്റ്റാളറിനുള്ളിൽ ഉണ്ട്.

### വഴി 1: ഇൻസ്റ്റാളർ `ClipFinder-Setup.exe` (ശുപാർശ)
GitHub-ൽ "Build Windows installer" ഓടിച്ചാൽ ഉണ്ടാകും (`.github/workflows/build-windows.yml`; Actions → ആ പേര് → Run workflow;
ഫലം പേജിന്റെ താഴെ "Artifacts"-ൽ **1 ദിവസം മാത്രം** നിൽക്കും, അതിനുള്ളിൽ ഡൗൺലോഡ് ചെയ്യുക). ബിൽഡിൽ വീഡിയോകൾ ഒന്നുമില്ല.
1. `ClipFinder-Setup.exe` ഡബിൾ ക്ലിക്ക് ചെയ്യുക. അഡ്മിൻ അനുമതി വേണ്ട (നിങ്ങളുടെ അക്കൗണ്ടിന് മാത്രമായി ഇൻസ്റ്റാൾ ആകും).
2. വീഡിയോകളും ക്ലിപ്പുകളും സൂക്ഷിക്കേണ്ട ഫോൾഡർ ചോദിക്കും (`D:\Clipfinder` ഉണ്ടെങ്കിൽ അതിനുള്ളിലെ `data` ആണ് ആദ്യം കാണിക്കുക). അൺഇൻസ്റ്റാൾ ചെയ്താലും ഈ ഫോൾഡർ മായില്ല.
3. Start Menu-വിലോ Desktop-ലോ "ClipFinder" തുറക്കുക. ചെറിയ ആപ്പ് ജാലകം തുറക്കും. കൂടെ വരുന്ന കറുത്ത ജാലകം പ്രോഗ്രാം ഓടുന്നു എന്നതിന്റെ സൂചനയാണ്; അത് അടയ്ക്കരുത്.
4. **മുന്നറിയിപ്പ്:** ഇൻസ്റ്റാളറിന് ഡിജിറ്റൽ ഒപ്പ് (code signing) ഇല്ല. അതിനാൽ Windows SmartScreen "Windows protected your PC" കാണിക്കുകയോ ചില ആന്റിവൈറസുകൾ തടയുകയോ ചെയ്തേക്കാം
   (ഇത് എന്റെ പൊതുവായ അറിവാണ്, ഇവിടെ പരീക്ഷിക്കാൻ കഴിഞ്ഞില്ല). നിങ്ങളുടെ സ്വന്തം GitHub-ൽ ഉണ്ടാക്കിയ ഫയൽ ആണെങ്കിൽ "More info → Run anyway".

**ഇൻസ്റ്റാളറിനുള്ളിൽ ആവശ്യമായ എല്ലാം ഉണ്ട്; വേറെ ഒന്നും ഇൻസ്റ്റാൾ ചെയ്യേണ്ട:**
- Python 3.12 + numpy: `ClipFinder.exe`-യുടെ ഫോൾഡറിനുള്ളിൽ (കമ്പ്യൂട്ടറിൽ Python ഇൻസ്റ്റാൾ ചെയ്തിരിക്കണമെന്നില്ല).
- ഫയൽ തിരഞ്ഞെടുക്കൽ ജാലകം (tkinter, Tcl/Tk): ഉള്ളിൽ.
- Visual C++ റൺടൈം DLL-കൾ (`vcruntime140` തുടങ്ങിയവ; Python-നും numpy-ക്കും വേണം): ഉള്ളിൽ.
- ffmpeg, ffprobe, yt-dlp: `tools` ഫോൾഡറിൽ (yt-dlp.exe-ക്ക് സ്വന്തം Python ഉള്ളിലുണ്ട്).
- ആപ്പിന്റെ പേജ് (HTML, JS, CSS): ഉള്ളിൽ.
- **.NET, Java, Node എന്നിവ ഒന്നിനും വേണ്ട.** ഈ ആപ്പ് Python + HTML + ffmpeg + yt-dlp മാത്രമാണ്; ഇൻസ്റ്റാളറും .NET ഉപയോഗിക്കുന്നില്ല.
- Windows-ൽ നിന്ന് വേണ്ടത്: Windows 10/11 (64-bit), ഒരു ബ്രൗസർ (Edge Windows-ൽ ഉണ്ട്). ഇന്റർനെറ്റ് വേണ്ടത് YouTube ലിങ്ക് ഡൗൺലോഡിനും yt-dlp അപ്ഡേറ്റിനും മാത്രം.

**ഇത് ഉറപ്പാക്കുന്നത് എങ്ങനെ (GitHub ബിൽഡിൽ യാന്ത്രികമായി):**
1. `packaging/check_bundle.py`: ഓരോ പ്രോഗ്രാം ഫയലും (.exe/.dll/.pyd) തുറന്ന് അതിന് വേണ്ട DLL-കളുടെ പട്ടിക എടുക്കും. ഓരോന്നും ഫോൾഡറിനുള്ളിൽ ഉണ്ടോ, അല്ലെങ്കിൽ Windows-ന്റെ സ്വന്തം DLL ആണോ എന്ന് നോക്കും. Visual C++ റൺടൈം Windows-ൽ ഉണ്ടെങ്കിലും ഫോൾഡറിനുള്ളിൽ തന്നെ വേണം. എന്തെങ്കിലും കുറഞ്ഞാൽ ബിൽഡ് പരാജയപ്പെടും, തെറ്റായ ഇൻസ്റ്റാളർ ഉണ്ടാകില്ല.
2. ഇൻസ്റ്റാളർ ശരിക്കും (silent ആയി) ഇൻസ്റ്റാൾ ചെയ്ത്, അതേ പരിശോധനയും ഒരു പൂർണ്ണ ഓട്ടപരീക്ഷയും (വിശകലനം, ക്ലിപ്പ് നിർമ്മാണം) നടത്തും, പിന്നെ അൺഇൻസ്റ്റാൾ ചെയ്യും. ഈ ഓട്ടപരീക്ഷയിൽ പ്രോഗ്രാമിന് Python, ffmpeg, yt-dlp ഒന്നും PATH-ൽ ഇല്ലാത്ത "ശൂന്യ" എൻവയോൺമെന്റ് ആണ് കൊടുക്കുന്നത്.
3. **ഇതുവരെ ഇതൊന്നും Windows-ൽ ഓടിച്ചിട്ടില്ല** (ആദ്യ GitHub ബിൽഡിൽ ആദ്യമായി ഓടും). ഇവിടെ Linux-ൽ ഇതേ ഓട്ടപരീക്ഷ പാക്കേജ് ചെയ്ത പ്രോഗ്രാമിൽ വിജയിച്ചു (yt-dlp ഒരു ഡമ്മി ആയിരുന്നു, ffmpeg യഥാർത്ഥം); DLL പരിശോധന യഥാർത്ഥ Windows ഫയലുകളിൽ (numpy-യുടെ Windows പാക്കേജ്) പരീക്ഷിച്ചപ്പോൾ അവയ്ക്ക് `python312.dll`, `vcruntime140.dll`, `vcruntime140_1.dll` വേണമെന്ന് ശരിയായി കണ്ടെത്തി.
4. പരിമിതി: പ്രോഗ്രാം ഓടുമ്പോൾ മാത്രം പേര് നോക്കി ലോഡ് ചെയ്യുന്ന DLL-കൾ (`LoadLibrary`) DLL പരിശോധനയിൽ കാണില്ല. GitHub യന്ത്രത്തിൽ Visual C++ ഇൻസ്റ്റാൾ ചെയ്തിട്ടുള്ളതിനാൽ "ശൂന്യ" ഓട്ടപരീക്ഷ മാത്രം, VC++ ഇല്ലാത്ത കമ്പ്യൂട്ടറിൽ ഓടുമെന്ന് തെളിയിക്കില്ല; അത് തെളിയിക്കുന്നത് DLL പരിശോധനയാണ്.

### വഴി 2: ZIP (ഇൻസ്റ്റാളർ ഇല്ലാതെ)
1. zip എക്സ്ട്രാക്ട് ചെയ്യുക.
2. `setup_windows.bat` ഒരിക്കൽ ഡബിൾ ക്ലിക്ക്: winget വഴി Python, ffmpeg എന്നിവയും pip വഴി numpy, yt-dlp-യും ഇൻസ്റ്റാൾ ചെയ്യും. **Windows-ൽ ഇതുവരെ പരീക്ഷിച്ചിട്ടില്ല**;
   ഏതെങ്കിലും വരി പരാജയപ്പെട്ടാൽ സന്ദേശം അയച്ചുതരിക. കഴിഞ്ഞാൽ ആ ജാലകം അടയ്ക്കുക (പുതിയ ജാലകത്തിൽ മാത്രമേ പുതിയ പ്രോഗ്രാമുകൾ കാണൂ).
   കൈകൊണ്ട് ചെയ്യണമെങ്കിൽ: Python 3.10+ (python.org; "Add Python to PATH" ടിക്ക്), `winget install Gyan.FFmpeg`, `pip install numpy yt-dlp`.
3. ഓരോ തവണയും `start_clipfinder.bat` ഡബിൾ ക്ലിക്ക് ചെയ്യുക.

### തുറക്കുന്ന വിധം, നിർത്തുന്ന വിധം
- ആപ്പ് Edge/Chrome-ന്റെ ചെറിയ "ആപ്പ് ജാലകം" ആയി (ടാബും വിലാസ ബാറും ഇല്ലാതെ) തുറക്കും. അവ കണ്ടെത്താനായില്ലെങ്കിൽ സാധാരണ ബ്രൗസറിൽ തുറക്കും.
  സാധാരണ ടാബ് വേണമെങ്കിൽ `clipfinder_web.py --tab` (അല്ലെങ്കിൽ `ClipFinder.exe --tab`). ഒന്നും തുറക്കേണ്ടെങ്കിൽ `--no-browser`; അപ്പോൾ കറുത്ത ജാലകത്തിലെ ലിങ്ക് ബ്രൗസറിൽ ഒട്ടിക്കുക.
- ആപ്പ് ജാലകം അടച്ചാൽ പ്രോഗ്രാം നിൽക്കില്ല. നിർത്താൻ: ക്രമീകരണങ്ങളിൽ "ആപ്പ് അടയ്ക്കുക", അല്ലെങ്കിൽ കറുത്ത ജാലകത്തിൽ Ctrl+C, അല്ലെങ്കിൽ ആ ജാലകം അടയ്ക്കുക.
- ക്രമീകരണങ്ങളിലെ **"yt-dlp അപ്ഡേറ്റ് ചെയ്യുക"** ബട്ടൺ: YouTube ലിങ്ക് ഡൗൺലോഡ് പെട്ടെന്ന് പരാജയപ്പെട്ടു തുടങ്ങിയാൽ (YouTube മാറുമ്പോൾ yt-dlp പഴയതാകും) ഇത് അമർത്തുക. ഇന്റർനെറ്റ് വേണം; ഒരു ജോലി നടക്കുമ്പോൾ അനുവദിക്കില്ല.
- **ഭാഷ:** മുകളിൽ വലതുവശത്തെ **"മലയാളം | English"** ബട്ടണിൽ ആപ്പ് മുഴുവൻ ഭാഷ മാറ്റാം. തിരഞ്ഞെടുത്ത ഭാഷ ഡാറ്റ ഫോൾഡറിലെ `prefs.json`-ൽ ഓർമ്മിക്കും.
- **ലേഔട്ടുകൾ:** "ബ്ലർ പശ്ചാത്തലം" (സ്ക്രീൻ മുഴുവൻ), "ക്രോപ്പ്" (നിശ്ചിത ഭാഗം), "ചലനം പിന്തുടരുക" (ക്രോപ്പ് ചലനമുള്ള ഭാഗത്തിന്റെ കൂടെ നീങ്ങും; കഥാപാത്രത്തെ തിരിച്ചറിയുന്നില്ല). "ഈ ലേഔട്ട് എല്ലാ ക്ലിപ്പിനും" ബട്ടൺ ഒറ്റയടിക്ക് എല്ലാറ്റിനും ബാധകമാക്കും.
- **Claude കണക്ടറിലെ പുതിയ ടൂളുകൾ:** `app_info` (പതിപ്പും സൗകര്യങ്ങളും), `get_clip_frame` (ഉണ്ടാക്കിയ ക്ലിപ്പിന്റെ ചിത്രം; `--images` ഓണാക്കിയാൽ മാത്രം).

- **YouTube-ലേക്ക് നേരിട്ട് അപ്‌ലോഡ് (ഓപ്ഷണൽ):** ക്രമീകരണങ്ങൾ → "YouTube-ലേക്ക് നേരിട്ട് അപ്‌ലോഡ്" എന്നതിലെ ഘട്ടങ്ങൾ ഒരിക്കൽ ചെയ്താൽ, അവസാന സ്ക്രീനിൽ ഓരോ ക്ലിപ്പിനും അപ്‌ലോഡ് ബട്ടൺ വരും. നിങ്ങൾ അമർത്തുന്ന ക്ലിപ്പ് മാത്രം YouTube-ലേക്ക് പോകും. ഡാറ്റ ഫോൾഡറിലെ `youtube_client.json`, `.youtube-token` എന്നിവ രഹസ്യമായി സൂക്ഷിക്കുക; അവ GitHub-ലേക്കോ മറ്റാർക്കോ കൊടുക്കരുത്.

അതിനുള്ളിൽ ആപ്പ് രണ്ട് ഫോൾഡറുകൾ ഉണ്ടാക്കും:

- `analyses\<കോഡ്>\clips`: ഉണ്ടാക്കിയ Shorts ഇവിടെ സേവ് ആകും ("ഫോൾഡർ തുറക്കുക" ബട്ടൺ ഇങ്ങോട്ട് കൊണ്ടുപോകും). ഓരോ വിശകലനത്തിന്റെയും സേവ് ചെയ്ത ഫലങ്ങളും (അടുത്ത തവണ ഉടൻ തുറക്കാൻ) ഇവിടെയാണ്.


## 5 ഘട്ടം
1. **ഹോം:** വീഡിയോ ഫയൽ ജാലകത്തിലേക്ക് വലിച്ചിടുക, അല്ലെങ്കിൽ "ഫയൽ തിരഞ്ഞെടുക്കുക" അമർത്തുക, അല്ലെങ്കിൽ YouTube ലിങ്ക് (അല്ലെങ്കിൽ ഫയലിന്റെ പാത്ത്) ഒട്ടിക്കുക.
2. **വിശകലനം:** പുരോഗതി കാണിക്കും; റദ്ദാക്കാം. (1080p60 വീഡിയോ ഇവിടെ ഏകദേശം 11 മടങ്ങ് വേഗത്തിൽ വിശകലനം ചെയ്തു: 2 മണിക്കൂർ സ്ട്രീമിന് ഏകദേശം 10 മിനിറ്റ്; നിങ്ങളുടെ PC-യിൽ വ്യത്യാസപ്പെടും. ഒരിക്കൽ ചെയ്താൽ അടുത്ത തവണ ഉടൻ തുറക്കും.)
   **YouTube ലിങ്ക് ആണെങ്കിൽ:** സമയം ലാഭിക്കാൻ ആദ്യം ചെറിയ (~360p) കോപ്പി മാത്രം ഡൗൺലോഡ് ചെയ്ത് അതിൽ നിന്ന് ഭാഗങ്ങൾ കണ്ടെത്തും (അവലോകന പേജിൽ കാണുന്നത് ആ ചെറിയ കോപ്പിയാണ്). ക്ലിപ്പ് ഉണ്ടാക്കുമ്പോൾ നിങ്ങൾ തിരഞ്ഞെടുത്ത ഭാഗങ്ങൾ മാത്രം
   (മുന്നിലും പിന്നിലും 3 സെക്കൻഡ് അധികം) 1080p-യിൽ ഡൗൺലോഡ് ചെയ്യും. ഒരു ഭാഗം ഡൗൺലോഡ് ആയില്ലെങ്കിൽ, അല്ലെങ്കിൽ ലഭിച്ച ഭാഗത്തിന്റെ നീളം ശരിയല്ലെങ്കിൽ, മുഴുവൻ വീഡിയോ ഒരിക്കൽ 1080p-യിൽ ഡൗൺലോഡ് ചെയ്ത് അതിൽ നിന്ന് മുറിക്കും.
   **ഈ ഭാഗം യഥാർത്ഥ YouTube-ൽ പരീക്ഷിച്ചിട്ടില്ല** (ഇവിടെ നിന്ന് YouTube-ലേക്ക് ബന്ധമില്ല; പകരം ഡമ്മി yt-dlp ഉപയോഗിച്ചാണ് ടെസ്റ്റ്). ആദ്യ ഉപയോഗത്തിൽ ഫലം നോക്കി പറയുക.
3. **ക്ലിപ്പുകൾ:** ചിത്രത്തിൽ ക്ലിക്ക് ചെയ്ത് തിരഞ്ഞെടുക്കുക, ▶ അമർത്തി കണ്ടുനോക്കുക. മുകളിൽ "എന്ത് കണ്ടെത്തണം?" (എല്ലാം / ആക്ഷൻ / സ്ലോ-മോഷൻ / ക്ലച്ച് / ആർപ്പ്) തിരഞ്ഞെടുക്കാം; സ്ലൈഡർ "കൂടുതൽ ക്ലിപ്പുകൾ" ↔ "കൂടുതൽ കൃത്യത".
4. **ഉണ്ടാക്കാം:** ഓരോ ക്ലിപ്പിനും ലേഔട്ട് (ബ്ലർ പശ്ചാത്തലം / ക്രോപ്പ്), തുടക്കവും അവസാനവും (വെള്ള അറ്റങ്ങൾ വലിക്കുക), ശീർഷകം.
5. **തയ്യാർ:** ഫയലുകൾ കാണുക, ഫോൾഡർ തുറക്കുക, YouTube Studio-വിൽ നിങ്ങൾ തന്നെ അപ്‌ലോഡ് ചെയ്യുക.

## ഇത് എന്ത് ചെയ്യും / ചെയ്യില്ല
- ചെയ്യും: ശബ്ദം ഉയരുന്ന ഭാഗം, സംസാര ബാൻഡിൽ (ആർപ്പ്/ഉച്ചത്തിലുള്ള സംസാരം) ശബ്ദം കൂടുന്ന ഭാഗം, ചലനം കൂടുന്ന ഭാഗം, ശാന്തതയ്ക്ക് ശേഷമുള്ള പൊട്ടിത്തെറി, സ്ലോ-മോഷൻ പോലുള്ള ഭാഗം കണ്ടെത്തും.
- ചെയ്യില്ല: "നല്ല" ക്ലിപ്പ് ഏതെന്ന് മനസ്സിലാക്കില്ല. "ശബ്ദമുള്ള/തിരക്കുള്ള" ഭാഗമാണ് കണ്ടെത്തുന്നത്; "സാധ്യത: ഉയർന്നത്" എന്നാൽ നല്ലത് എന്നല്ല, മാറ്റം വലുത് എന്നാണ്.
- സ്ലോ-മോഷൻ കണ്ടെത്തൽ ഒരു ഊഹ രീതിയാണ് (ചലനം പെട്ടെന്ന് കുറയുക + ശബ്ദം മങ്ങുക). തെറ്റാം.
- YouTube-ലേക്ക് നേരിട്ട് അപ്‌ലോഡ് ചെയ്യില്ല; ഇപ്പോൾ ശീർഷകം ഫയലിന്റെ പേരായി മാത്രം ഉപയോഗിക്കും (വീഡിയോയിൽ എഴുതില്ല).
- "ഫേസ്‌ക്യാം + ഗെയിം" ലേഔട്ട് ഇപ്പോൾ ഇല്ല ("ഉടൻ വരും" എന്ന് കാണിക്കും).
- **പ്രധാനം:** ഇതുവരെ പരീക്ഷിച്ചത് കൃത്രിമമായി ഉണ്ടാക്കിയ ഡമ്മി വീഡിയോയിൽ മാത്രമാണ്. നിങ്ങളുടെ PS5 ഫൂട്ടേജിൽ ഫലം വ്യത്യസ്തമാകാം; ക്ലിപ്പുകൾ കൂടുതലോ കുറവോ വന്നാൽ സ്ലൈഡർ ഉപയോഗിക്കുക.

## ഫയൽ ചേർക്കുന്ന വഴികൾ (കോപ്പി ചെയ്യുമോ?)
- **വലിച്ചിടുക / ബ്രൗസർ വഴി തിരഞ്ഞെടുക്കുക:** ഫയൽ `videos` ഫോൾഡറിലേക്ക് **കോപ്പി** ചെയ്യും (ബ്രൗസറുകൾ ഫയലിന്റെ യഥാർത്ഥ സ്ഥാനം തരില്ല). വലിയ ഫയലിന് സമയവും ഡിസ്ക് സ്ഥലവും വേണം.

- **പാത്ത് ഒട്ടിക്കുക:** ലിങ്ക് ബോക്സിൽ `D:\...\stream.mp4` ഒട്ടിച്ചാലും മതി; കോപ്പി ചെയ്യില്ല.

**Claude-ന് കഴിയാത്തത്:** ഈ ഫോൾഡറിനു പുറത്തുള്ള ഫയൽ വായിക്കുക, സ്വന്തം പാത്ത് കൊടുക്കുക, ഡിലീറ്റ് ചെയ്യുക, അപ്‌ലോഡ് ചെയ്യുക, പ്രോഗ്രാം അപ്ഡേറ്റ് ചെയ്യുക, ആപ്പ് അടയ്ക്കുക.
1. ClipFinder തുറക്കുക → ക്രമീകരണങ്ങൾ → **"Claude-മായി ബന്ധിപ്പിക്കുക"**.
2. Claude Desktop-ൽ: Settings → Developer → **Edit Config**. തുറക്കുന്ന `claude_desktop_config.json`-ൽ ആപ്പ് കാണിക്കുന്ന ഭാഗം ചേർക്കുക (ഫയലിൽ ഇതിനകം `mcpServers` ഉണ്ടെങ്കിൽ അതിനുള്ളിൽ `clipfinder` മാത്രം). സേവ് ചെയ്ത് **Claude Desktop പൂർണ്ണമായി അടച്ച് (ട്രേയിൽ നിന്നും) വീണ്ടും തുറക്കുക**.
   Claude Code ആണെങ്കിൽ ആപ്പ് കാണിക്കുന്ന `claude mcp add …` വരി ടെർമിനലിൽ ഓടിക്കുക.
3. "ഇവിടെ പരീക്ഷിക്കുക" അമർത്തിയാൽ കണക്ടർ ശരിയായി തുടങ്ങുന്നുണ്ടോ എന്ന് ആപ്പ് തന്നെ നോക്കും (ഇത് Claude-ൽ ചേർത്തോ എന്ന് പരിശോധിക്കുന്നില്ല; അത് Claude-ൽ ടൂളുകൾ കാണുന്നുണ്ടോ എന്ന് നോക്കി ഉറപ്പാക്കുക).
- ക്ലിപ്പ് ഉണ്ടാക്കുന്നതും വിശകലനവും ഒരു സമയം ഒന്ന് മാത്രം; ആപ്പിന്റെ ജാലകവും Claude-ഉം ഒരുമിച്ച് ജോലി തുടങ്ങിയാൽ രണ്ടാമത്തേത് "തിരക്കിലാണ്" എന്ന് പറയും.
- Claude ഉണ്ടാക്കിയ വിശകലനങ്ങൾ ആപ്പിലെ ലൈബ്രറിയിൽ പേജ് പുതുക്കിയാൽ കാണാം.
- **സ്വകാര്യത:** Claude-ലേക്ക് പോകുന്നത്: ഫയൽ പേരുകൾ, ക്ലിപ്പ് സമയം/സ്കോർ, ക്ലിപ്പ് ഫോൾഡറിന്റെ സ്ഥാനം. "ചിത്രം" ഓപ്ഷൻ ഓൺ ആണെങ്കിൽ ക്ലിപ്പിന്റെ ഒരു ഫ്രെയിം (Anthropic-ലേക്ക് അയയ്ക്കപ്പെടും). ഫയൽ പേരിൽ എഴുതിയ നിർദ്ദേശങ്ങൾ Claude അനുസരിക്കാതിരിക്കാൻ പേരുകൾ വൃത്തിയാക്കി "ഡാറ്റ" എന്ന് അടയാളപ്പെടുത്തിയാണ് നൽകുന്നത്; എങ്കിലും അപരിചിതമായ പേരുള്ള ഫയലുകൾ `videos` ഫോൾഡറിൽ ഇടരുത്.
- **Windows-ൽ ഇതുവരെ Claude Desktop-ൽ പരീക്ഷിച്ചിട്ടില്ല.** ഇവിടെ ഔദ്യോഗിക MCP SDK-യുടെ ക്ലയന്റ് ഉപയോഗിച്ചും, പാക്കേജ് ചെയ്ത പ്രോഗ്രാമിലും പരീക്ഷിച്ചു. `ClipFinder.exe` കൺസോൾ പ്രോഗ്രാം ആയതിനാൽ Claude തുറക്കുമ്പോൾ ഒരു കറുത്ത ജാലകം മിന്നിയേക്കാം (ഉറപ്പില്ല).

## മറ്റ് ഉപകരണങ്ങളിൽ നിന്ന് ഉപയോഗിക്കുക — Tailscale (ഓപ്ഷണൽ, സ്വതവേ ഓഫ്)
PC-യിൽ ClipFinder ഓടുമ്പോൾ ഫോണിൽ/ലാപ്ടോപ്പിൽ നിന്ന് ഇതേ പേജ് തുറക്കാം. ഇന്റർനെറ്റിൽ പൊതുവായി തുറക്കുന്നില്ല; Tailscale (സൗജന്യ സ്വകാര്യ നെറ്റ്‌വർക്ക്) വഴി നിങ്ങളുടെ ഉപകരണങ്ങൾക്ക് മാത്രം, രഹസ്യ ലിങ്കും വേണം.
1. PC-യിലും ഫോണിലും Tailscale ഇൻസ്റ്റാൾ ചെയ്ത് ഒരേ അക്കൗണ്ടിൽ ലോഗിൻ. അഡ്മിൻ പേജിൽ DNS → **MagicDNS**, **HTTPS certificates** ഓൺ.
2. ClipFinder → ക്രമീകരണങ്ങൾ → "മറ്റ് ഉപകരണങ്ങളിൽ നിന്ന് ഉപയോഗിക്കുക": PC-യുടെ Tailscale പേര് (`പേര്.tailXXXX.ts.net`) കൊടുത്ത് സേവ് ചെയ്യുക; ClipFinder അടച്ച് വീണ്ടും തുറക്കുക.
3. PC-യിൽ ഒരിക്കൽ: `tailscale serve --bg 8765` (ആപ്പ് മറ്റൊരു പോർട്ടിൽ തുടങ്ങിയെങ്കിൽ ആ നമ്പർ; ആപ്പ് ഇത് കാണിക്കും). **`funnel` ഉപയോഗിക്കരുത്** (അത് ഇന്റർനെറ്റിൽ പൊതുവായി തുറക്കും). നിർത്താൻ: `tailscale serve reset`.
4. ആപ്പ് കാണിക്കുന്ന ലിങ്ക് (`https://…ts.net/?t=…`) ഫോണിൽ തുറക്കുക. ഈ ലിങ്ക് രഹസ്യമാണ്: ആരുമായും പങ്കിടരുത്.
- ദൂരെ നിന്നുള്ള പേജിൽ "ഫയൽ ജാലകം", "ഫോൾഡർ തുറക്കുക", "yt-dlp അപ്ഡേറ്റ്", "ആപ്പ് അടയ്ക്കുക", കണക്ടർ/Tailscale ക്രമീകരണം എന്നിവ കാണില്ല (അവ PC-യിൽ നേരിട്ട് മാത്രം). ഫോണിൽ നിന്ന് വലിയ വീഡിയോ അപ്‌ലോഡ് ചെയ്യുന്നത് വളരെ പതുക്കെ ആയിരിക്കും; YouTube ലിങ്ക് കൊടുക്കുന്നതാണ് നല്ലത്.
- ഈ ഓപ്ഷൻ ഓൺ ആക്കുമ്പോൾ മാത്രം രഹസ്യ ടോക്കൺ ഓരോ തവണയും മാറാതെ ഡാറ്റ ഫോൾഡറിലെ `.remote-token` ഫയലിൽ സൂക്ഷിക്കും (അതിനാലാണ് ഫോണിലെ ലിങ്ക് തുടർന്നും പ്രവർത്തിക്കുന്നത്). ആ ഫയൽ ആർക്കും കാണിക്കരുത്; ലിങ്ക് ചോർന്നെന്ന് തോന്നിയാൽ ഫയൽ ഡിലീറ്റ് ചെയ്ത് ആപ്പ് വീണ്ടും തുടങ്ങുക.
- **ഇതുവരെ Tailscale-ൽ പരീക്ഷിച്ചിട്ടില്ല** (ഇവിടെ Tailscale ഇല്ല). ആപ്പിന്റെ ഭാഗം (പേര്/ഒറിജിൻ പരിശോധന, ടോക്കൺ, പരിമിതപ്പെടുത്തൽ) ടെസ്റ്റുകൾ ഉള്ളതാണ്; `tailscale serve` ഭാഗം നിങ്ങളുടെ PC-യിൽ ആദ്യമായി ഓടും.

## സുരക്ഷ (ബ്രൗസർ ആപ്പ്)
- സെർവർ **127.0.0.1-ൽ മാത്രം** കേൾക്കുന്നു (നിങ്ങളുടെ PC-യിൽ നിന്ന് മാത്രം; Wi-Fi/നെറ്റ്‌വർക്ക് വഴി ആർക്കും തുറക്കാൻ കഴിയില്ല). ഓരോ തവണ തുടങ്ങുമ്പോഴും പുതിയ രഹസ്യ ടോക്കൺ; അത് ഒരിക്കൽ ലിങ്കിൽ, പിന്നെ കുക്കിയിൽ (HttpOnly, SameSite=Strict).
- Host, Origin, Sec-Fetch-Site, custom header പരിശോധനകൾ: വേറെ വെബ്‌സൈറ്റോ വേറെ localhost പേജോ ഈ ആപ്പിനെ വിളിക്കാൻ ശ്രമിച്ചാൽ നിരസിക്കും. CORS ഇല്ല. കർശന Content-Security-Policy (ഇൻലൈൻ സ്ക്രിപ്റ്റ്/eval ഇല്ല, പുറത്തേക്ക് അഭ്യർത്ഥന ഇല്ല).
- പേജിൽ നിന്നുള്ള ഓരോ മൂല്യവും പരിശോധിക്കുന്നു (ID 12 ഹെക്സ് അക്കം, സംഖ്യകളുടെ പരിധി, ഫയൽ വീഡിയോ തരം ആകണം). ഫയലുകൾ നിശ്ചിത സ്ഥലങ്ങളിൽ നിന്ന് മാത്രം നൽകും (പേജിന്റെ 3 ഫയൽ, തിരഞ്ഞെടുത്ത വീഡിയോ, ക്ലിപ്പ് ഫോൾഡർ).
- ffmpeg/yt-dlp എപ്പോഴും ലിസ്റ്റ് ആർഗ്യുമെന്റായി (shell ഇല്ല); YouTube ലിങ്ക് `https://youtube.com`/`youtu.be` മാത്രം.
- പേജ് ഇന്റർനെറ്റ് ഇല്ലാതെയും പ്രവർത്തിക്കും: പുറത്തുനിന്നുള്ള ഫോണ്ടോ സ്ക്രിപ്റ്റോ ലോഡ് ചെയ്യുന്നില്ല (ടെസ്റ്റ് ഇത് പരിശോധിക്കുന്നു). YouTube ലിങ്ക് ഡൗൺലോഡിന് മാത്രം yt-dlp ഇന്റർനെറ്റ് ഉപയോഗിക്കും.
- ഇൻസ്റ്റാൾ ചെയ്ത രൂപത്തിൽ ffmpeg, ffprobe, yt-dlp എന്നിവ ആപ്പിന്റെ സ്വന്തം `tools` ഫോൾഡറിൽ നിന്നാണ് എടുക്കുന്നത്, അവ പൂർണ്ണ പാത്ത് ഉപയോഗിച്ച് തുടങ്ങുന്നു; ഷോർട്ട്കട്ട് പ്രോഗ്രാം ഫോൾഡറിൽ നിന്ന് തുടങ്ങുന്നു (വീഡിയോ ഫോൾഡറിൽ ഒളിപ്പിച്ച വ്യാജ `ffmpeg.exe` ഓടാതിരിക്കാൻ).

  1. yt-dlp അപ്ഡേറ്റ് പരാജയപ്പെട്ടാലും "ഇതിലും പുതിയത് കിട്ടിയില്ല" എന്ന് പറയുമായിരുന്നു. ഇപ്പോൾ കമാൻഡ് വിജയിച്ചാൽ മാത്രമേ വിജയം പറയൂ.
  2. ഡൗൺലോഡ് ഇടയ്ക്ക് നിന്നാൽ ബാക്കിയാകുന്ന ശബ്ദമില്ലാത്ത പകുതി ഫയൽ "ഡൗൺലോഡ് കഴിഞ്ഞത്" ആയി ഉപയോഗിക്കാൻ സാധ്യത ഉണ്ടായിരുന്നു. ഇപ്പോൾ കൃത്യമായ ഫയൽ പേര് മാത്രം സ്വീകരിക്കും.
  3. ഇൻസ്റ്റാളർ ഷോർട്ട്കട്ട് വീഡിയോ ഫോൾഡറിൽ നിന്ന് പ്രോഗ്രാം തുടങ്ങുമായിരുന്നു (Windows ഇപ്പോഴത്തെ ഫോൾഡറിലെ വ്യാജ `ffmpeg.exe` ഓടിക്കാൻ സാധ്യത). ഇപ്പോൾ പ്രോഗ്രാം ഫോൾഡറിൽ നിന്ന്; പൂർണ്ണ പാത്ത്; `NoDefaultCurrentDirectoryInExePath` സെറ്റ് ചെയ്തു (ഇതിന്റെ ഫലം Windows-ൽ പരിശോധിച്ചിട്ടില്ല).
  4. ഇൻസ്റ്റാളറിന്റെ സ്വതവേയുള്ള ഡാറ്റ ഫോൾഡർ "Documents" ആയിരുന്നു (OneDrive ഇത് സിങ്ക് ചെയ്ത് വലിയ വീഡിയോകൾ അപ്ലോഡ് ചെയ്യാം). മാറ്റി.
  5. ബിൽഡിലെ പാക്കേജ് പതിപ്പുകൾ ഉറപ്പിച്ചു (numpy 2.5.3, PyInstaller 6.22.3).
  6. പൈപ്പ് വഴി ഓടിക്കുമ്പോൾ ആരംഭ സന്ദേശവും ലിങ്കും വൈകി വരുന്ന പ്രശ്നം പാക്കേജ് ചെയ്ത രൂപത്തിൽ പരീക്ഷിച്ചപ്പോൾ കണ്ടു; ഇപ്പോൾ ഉടൻ പ്രിന്റ് ചെയ്യുന്നു.
  7. numpy-ക്ക് Visual C++ റൺടൈം DLL-കൾ വേണമെന്ന് യഥാർത്ഥ Windows ഫയലുകൾ തുറന്ന് നോക്കിയപ്പോൾ ഉറപ്പായി. അവ ഇൻസ്റ്റാളറിൽ നേരിട്ട് ഉൾപ്പെടുത്താൻ ബിൽഡ് റെസിപ്പിയിൽ ചേർത്തു; കൂടാതെ "വേറെ ഒന്നും ഇൻസ്റ്റാൾ ചെയ്യേണ്ട" എന്ന് ഓരോ ബിൽഡിലും യാന്ത്രികമായി പരിശോധിക്കുന്നു (മുകളിൽ കാണുക).
- **GitHub ബിൽഡ് (workflow) പരിശോധന:** കൈകൊണ്ടുള്ള ബട്ടൺ അമർത്തിയാൽ മാത്രം ഓടും; `contents: read` അനുമതി മാത്രം; രഹസ്യ കീകൾ ഒന്നുമില്ല; ffmpeg/yt-dlp ഡൗൺലോഡ് ആ റിലീസിലെ SHA-256 ഫയലുമായി ഒത്തുനോക്കും (പരാജയപ്പെട്ടാൽ ബിൽഡ് നിൽക്കും); ഫലം 1 ദിവസം മാത്രം സൂക്ഷിക്കും; `.gitignore` എല്ലാ വീഡിയോ/ഓഡിയോ തരങ്ങളും തടയുന്നു (ടെസ്റ്റ് ഇത് ഉറപ്പിക്കുന്നു).
- **ബാക്കിയുള്ള പരിമിതികൾ (മറച്ചുവെക്കുന്നില്ല):**
  - **Windows-ൽ ഒന്നും ഓടിച്ചിട്ടില്ല:** `.bat` ഫയലുകൾ, `setup_windows.bat`, Inno Setup സ്ക്രിപ്റ്റ്, Edge/Chrome ആപ്പ് ജാലകം, ഫയൽ ജാലകം, GitHub-ലെ Windows ബിൽഡ്. ആദ്യ ബിൽഡിൽ പിശക് വരാം; വന്നാൽ തിരുത്താം.
  - ബിൽഡിലെ GitHub Actions (`checkout`, `setup-python`, `upload-artifact`) പതിപ്പ് ടാഗിൽ ആണ്, commit SHA-യിൽ ഉറപ്പിച്ചിട്ടില്ല. SHA-256 പരിശോധന ഡൗൺലോഡ് കേടാകുന്നത് പിടിക്കും; ആ GitHub റിലീസ് തന്നെ ഹാക്ക് ചെയ്യപ്പെട്ടാൽ പിടിക്കില്ല. yt-dlp-യുടെ GPG ഒപ്പ് പരിശോധിക്കുന്നില്ല. Inno Setup Chocolatey വഴിയാണ് (പതിപ്പ് ഉറപ്പിച്ചിട്ടില്ല). ffmpeg ബിൽഡ് (BtbN, 8.1 ശാഖ) ദിവസവും പുതുക്കുന്ന "latest" റിലീസിൽ നിന്നാണ്; ആ ഫയൽ പേര് ഭാവിയിൽ ഇല്ലാതായാൽ ബിൽഡ് പരാജയപ്പെടും (അപ്പോൾ workflow-ലെ `FFMPEG_ZIP` മാറ്റണം).
  - ആപ്പ് ജാലകം നിങ്ങളുടെ സാധാരണ Edge/Chrome പ്രൊഫൈലിൽ തുറക്കും; ആ ബ്രൗസറിലെ എക്സ്റ്റൻഷനുകൾക്ക് ലോക്കൽ പേജ് കാണാൻ സാധ്യതയുണ്ട് (സാധാരണ ടാബിനും ഇതേ സ്ഥിതി). ആശങ്കയുണ്ടെങ്കിൽ `--tab` ഉപയോഗിച്ച് പ്രൈവറ്റ്/ഇൻകോഗ്നിറ്റോ ജാലകത്തിൽ തുറക്കുക.
  - ടോക്കൺ ഉള്ള ലിങ്ക് ആപ്പ് ജാലകം തുറക്കുന്ന കമാൻഡിലും ഉണ്ട് (പ്രോസസ് ലിസ്റ്റിൽ കാണാം). ഒറ്റ ഉപയോക്താവിന്റെ PC-ക്ക് പ്രശ്നമില്ല; പങ്കിട്ട കമ്പ്യൂട്ടറിൽ ഉപയോഗിക്കരുത്.
  - ഇൻസ്റ്റാളറിൽ ffmpeg-ന്റെ GPL ബിൽഡ് ആണ് (`THIRD_PARTY.txt`). ഇൻസ്റ്റാളർ മറ്റുള്ളവർക്ക് കൊടുക്കുകയാണെങ്കിൽ ആ ലൈസൻസ് ബാധകം; സ്വന്തം ഉപയോഗത്തിന് പ്രശ്നമില്ല.
  - yt-dlp അപ്ഡേറ്റ് ബട്ടൺ yt-dlp-യുടെ സ്വന്തം `-U` (ഇൻസ്റ്റാളർ രൂപം) അല്ലെങ്കിൽ `pip install --upgrade yt-dlp` (ZIP രൂപം) ആണ് ഓടിക്കുന്നത്. അവയുടെ ഉള്ളിലെ സുരക്ഷാ പരിശോധനകൾ ഞാൻ പരിശോധിച്ചിട്ടില്ല.
  - ഡിജിറ്റൽ ഒപ്പ് ഇല്ല (SmartScreen/ആന്റിവൈറസ് മുന്നറിയിപ്പ് വരാം).

### മുൻ ഓഡിറ്റ് (ബ്രൗസർ ആപ്പ് ആദ്യ പതിപ്പ്)
- അന്ന് കണ്ടെത്തി ശരിയാക്കിയത്: ചങ്ക് (chunked) ബോഡി അഭ്യർത്ഥനകൾ നിരസിക്കുന്നു; Windows-ൽ പോർട്ട് പങ്കിടൽ തടയാൻ `allow_reuse_address` ഓഫ്; വീഡിയോ ഒഴുക്കിനിടെ ബ്രൗസർ കണക്ഷൻ മുറിഞ്ഞാൽ ശബ്ദമുള്ള പിശക് പ്രിന്റ് ചെയ്യുന്നത് ഒഴിവാക്കി.
- ഇപ്പോഴും ബാധകമായ പരിമിതികൾ:
  - കുക്കികൾ പോർട്ട് അടിസ്ഥാനത്തിൽ വേർതിരിക്കപ്പെടുന്നില്ല (ബ്രൗസർ നിയമം). അതിനാലാണ് Origin/Host/Sec-Fetch പരിശോധനകളും ഓരോ തവണ പുതിയ ടോക്കണും.
  - HTTPS ഇല്ല (ലൂപ്ബാക്ക് ആയതിനാൽ). നിങ്ങളുടെ Windows ലോഗിൻ ഉപയോഗിക്കുന്ന മറ്റൊരാൾക്ക്/പ്രോഗ്രാമിന് ഇത് ഉപയോഗിക്കാം (ഏത് ലോക്കൽ ആപ്പിനും ബാധകം).
  - ffmpeg, yt-dlp, numpy, Python എന്നിവയുടെ സുരക്ഷ അവയുടേതാണ്; അപ്‌ഡേറ്റ് ചെയ്യുക. yt-dlp സ്വന്തം പ്ലഗിൻ ഫോൾഡറുകൾ ലോഡ് ചെയ്യാം.
  - ഡൗൺലോഡിനും ഡീകോഡിനും സമയപരിധി ഇല്ല (റദ്ദാക്കൽ ബട്ടൺ ഉണ്ട്).
  - Chrome/Edge (Chromium) ഉപയോഗിക്കുക; Firefox/Safari പരീക്ഷിച്ചിട്ടില്ല.
  - അപ്‌ലോഡ് വഴി ചേർത്ത ഫയലും YouTube-ൽ നിന്ന് ഡൗൺലോഡ് ചെയ്ത ഫയലുകളും ഡിസ്ക് സ്ഥലം എടുക്കും; ഇപ്പോൾ ആപ്പിൽ ഡിലീറ്റ് ബട്ടൺ ഇല്ല (ഫോൾഡറിൽ നിന്ന് കൈകൊണ്ട് മാറ്റാം).

# കമാൻഡ് ലൈൻ (ഓപ്ഷണൽ, മുകളിലെ ആപ്പിന് പകരം ടെർമിനലിൽ)

### YouTube ലിങ്കിൽ നിന്ന് നേരിട്ട് (ഓപ്ഷണൽ, **യഥാർത്ഥ YouTube-ൽ പരീക്ഷിച്ചിട്ടില്ല**)
`pip install yt-dlp` ചെയ്ത ശേഷം ഫയലിന് പകരം ലിങ്ക് കൊടുക്കുക (സ്വന്തം ചാനലിലെ വീഡിയോ മാത്രം ഉപയോഗിക്കുക):
```
python clipfinder.py analyze "https://www.youtube.com/watch?v=XXXX" --preset slowmo
```
- `https://youtube.com`, `youtu.be` ലിങ്കുകൾ മാത്രം സ്വീകരിക്കും. വീഡിയോ ഫലങ്ങളുടെ ഫോൾഡറിൽ `source.mp4` ആയി സേവ് ആകും (1080p വരെ).
- yt-dlp എന്ന ഇതര ടൂളാണ് ഡൗൺലോഡ് ചെയ്യുന്നത്; clipfinder-ൽ ഇപ്പോഴും നെറ്റ്‌വർക്ക് കോഡ് ഇല്ല.
- YouTube ചിലപ്പോൾ ഡൗൺലോഡ് തടയാം, yt-dlp പഴയതായാൽ പരാജയപ്പെടാം (`pip install -U yt-dlp`). അങ്ങനെ വന്നാൽ Studio-വിൽ നിന്ന് ഫയൽ എടുക്കുക.
- ടെസ്റ്റുകളിൽ ലിങ്ക് പരിശോധന ഡമ്മി downloader വച്ചാണ്.

### ഉപയോഗം
```
python clipfinder.py conditions                      # കണ്ടിഷനുകളുടെ ലിസ്റ്റ്
python clipfinder.py analyze stream.mp4              # എല്ലാ കണ്ടിഷനും
python clipfinder.py analyze stream.mp4 --preset slowmo
python clipfinder.py analyze stream.mp4 --preset clutch --top 10
python clipfinder.py analyze stream.mp4 --preset presets/slowmo_clutch.json
python clipfinder.py analyze stream.mp4 --require slow_motion,loud_peak   # രണ്ടും വേണം
python clipfinder.py analyze stream.mp4 --weights slow_motion=2,loud_peak=0.5
```
ഇത് `stream_clipfinder/report.html` ഉണ്ടാക്കും. ബ്രൗസറിൽ തുറക്കുക (ഫയൽ ഓഫ്‌ലൈൻ ആണ്, ഒന്നും അപ്‌ലോഡ് ചെയ്യില്ല).

**Presets:** `all` (എല്ലാം), `action` (ശബ്ദം+ചലനം), `slowmo` (സ്ലോ-മോഷൻ ഉള്ളവ മാത്രം), `clutch` (ശാന്തം→പൊട്ടിത്തെറി ഉള്ളവ മാത്രം), `voice` (ആർപ്പ്/ഉച്ചത്തിലുള്ള സംസാരം ഉള്ളവ മാത്രം).
`--use` = ഈ കണ്ടിഷനുകൾ ക്ലിപ്പ് ഉണ്ടാക്കാം; `--require` = ഓരോ ക്ലിപ്പിലും ഇവ നിർബന്ധം.
ഒരിക്കൽ വിശകലനം ചെയ്താൽ സിഗ്നലുകൾ സേവ് ആകും, അതിനാൽ കണ്ടിഷൻ മാറ്റി വീണ്ടും ഓടിക്കുന്നത് പെട്ടെന്ന് കഴിയും.

### റിപ്പോർട്ട് വായിക്കുന്ന വിധം
- ഓരോ കാർഡിലും സമയം, സ്കോർ ബാർ, കണ്ടിഷൻ ടാഗുകൾ, 3 ചെറു ചിത്രങ്ങൾ.
- മുകളിലെ ചിപ്പുകൾ ക്ലിക്ക് ചെയ്ത് ഫിൽട്ടർ ചെയ്യാം (തിരഞ്ഞെടുത്ത എല്ലാ ടാഗും ഉള്ളവ മാത്രം കാണും).
- ഇഷ്ടപ്പെട്ടവ ടിക്ക് ചെയ്യുക. താഴെ വരുന്ന കമാൻഡ് കോപ്പി ചെയ്യുക.
- സ്കോർ കൂടുതൽ = ശബ്ദ/ചലന മാറ്റം കൂടുതൽ. അത് "നല്ലത്" എന്നല്ല അർത്ഥം; സ്വയം കണ്ട് നോക്കുക.

### ക്ലിപ്പ് ഉണ്ടാക്കൽ
```
python clipfinder.py render stream_clipfinder --run <റിപ്പോർട്ടിലെ ID> --ids 1 3
python clipfinder.py render stream_clipfinder --run <ID> --ids 1 --layout crop --crop-x 0.5
python clipfinder.py render stream_clipfinder --run <ID> --ids 2 --pad-pre 3 --pad-post 3
```
- `blur` (സ്ഥിരം): ഗെയിം നടുവിൽ, പിന്നിൽ മങ്ങിയ പശ്ചാത്തലം. `crop`: സ്ക്രീനിന്റെ ഒരു ഭാഗം മുറിച്ച് മുഴുവൻ നിറയ്ക്കും (`--crop-x` 0=ഇടത് … 1=വലത്).
- `zoom` (ആപ്പിൽ ശുപാർശ): ഗെയിമിന്റെ ഒരു ചതുരം വലുതാക്കി ബ്ലർ പശ്ചാത്തലത്തിൽ; ആക്ഷന്റെ കൂടെ നീങ്ങും. `follow`: 9:16 ക്രോപ്പ് ആക്ഷന്റെ കൂടെ നീങ്ങും.
- Shorts 3 മിനിറ്റ് വരെ ആകാം (ചതുരം/ലംബം). `analyze` സ്ഥിരമായി 59 സെക്കൻഡിൽ താഴെ നിർത്തുന്നു; `--max-len 120` പോലെ കൂട്ടാം. ഒരു മിനിറ്റിൽ കൂടുതലുള്ള Short-ന് copyright claim വന്നാൽ ബ്ലോക്ക് ആകും, അതിനാൽ ചെറുതാണ് സുരക്ഷിതം.
- `--run` ID ഉള്ളത് പഴയ റിപ്പോർട്ടിലെ ID അബദ്ധത്തിൽ പുതിയ ലിസ്റ്റിൽ ഉപയോഗിക്കാതിരിക്കാനാണ്.
- ഫയലുകൾ `stream_clipfinder/clips/` ഫോൾഡറിൽ കിട്ടും.

### ഫലം അളക്കൽ (evaluate)
ഒരു സ്ട്രീമിൽ നിങ്ങൾക്ക് ഇഷ്ടപ്പെട്ട നിമിഷങ്ങളുടെ സമയം ഒരു ടെക്സ്റ്റ് ഫയലിൽ എഴുതുക (ഒരു വരിയിൽ ഒന്ന്: `1:35` അല്ലെങ്കിൽ `1:35-1:50`; `#` കഴിഞ്ഞാൽ കുറിപ്പ്):
```
python clipfinder.py evaluate stream_clipfinder my_moments.txt
```
ആപ്പ് എത്ര കണ്ടെത്തി (recall), ഏതൊക്കെ വിട്ടുപോയി, ഏത് കണ്ടിഷൻ എത്ര ശരിയായി എന്ന് കാണിക്കും. ത്രെഷോൾഡുകൾ ട്യൂൺ ചെയ്യാൻ ഇതാണ് ഏറ്റവും നല്ല വഴി.
"precision" ഒരു ഏകദേശ സൂചന മാത്രം: നിങ്ങൾ അടയാളപ്പെടുത്താത്ത ക്ലിപ്പും നല്ലതായിരിക്കാം.

### ട്യൂൺ ചെയ്യൽ
- കൂടുതൽ ക്ലിപ്പുകൾ വേണം: `--z-min 1.5 --min-score 0.2`. കുറച്ച് മതി/കൂടുതൽ കൃത്യത: `--z-min 3 --min-score 0.5`.
- തുടക്കത്തിലെ ലോബി/ലോഡിങ് ഒഴിവാക്കാൻ: `--skip-start 120`.
- ഒരേ കാര്യത്തിന് പല ക്ലിപ്പുകൾ വന്നാൽ: `--merge-gap 12`.
- മെനു/നിശ്ചല സ്‌ക്രീൻ സ്വതവേ ഒഴിവാക്കും; വേണമെങ്കിൽ `--keep-static`.
- സ്വന്തം preset: `presets/slowmo_clutch.json` പകർത്തി മാറ്റുക.
